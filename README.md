# serow-mechanism

ヤマハ セロー250（2008年式・3C56）を題材に、エンジンから後輪までの動力伝達を学ぶインタラクティブ教材です。SVGアニメーションで、シフト操作・クラッチ・歯車・チェーンの関係を観察できます。

HTML・CSS・JavaScript・SVGを単一ファイルに収めているため、インストールやサーバーの準備なしで動作します。

## 使い方

[index.html](index.html) をダウンロードし、ブラウザで開いてください。公開済みのGitHub Pages(https://naruo4.github.io/serow-mechanism/) では、そのままページ上で操作できます。

- 初期回転数は **60 rpm**。数値入力・スライダーでエンジン回転数を変更。
- 段送りは **1 ↔ N ↔ 2 ↔ 3 ↔ 4 ↔ 5**。各図のボタンから共通の状態を操作。
- クラッチを握る／離す操作で、プレッシャープレートと板群の変化を観察。
- 変速は通常2秒。タイムラインをドラッグして途中停止し、ドラム溝・フォーク・スライド部品・ドッグの関係を確認。
- 「変速のみ0.25×」で操作過程をスロー再生。エンジンの設定rpmは変わりません。
- 明暗の配色切替、機構図の拡大に対応。狭い画面では図の内部を横スクロールできます。

### キーボード

| キー | 操作 |
|---|---|
| `0` / `1`〜`5` | N / 各段を選択 |
| `↑` / `→` | シフトアップ |
| `↓` / `←` | シフトダウン |
| `C` | クラッチ接／断 |
| `Space` | 再生／一時停止 |

## 図解の内容

1. **ギア・シフトドラム・シフトフォーク**：固定・スライド・フリーの各部品を色分け。常時噛み合う歯車と、ドッグによる軸への締結を区別します。
2. **エンジン・一次減速・クラッチ内部**：単気筒ピストン、一次ギヤ、板群、ばね、レリーズ機構を表示します。
3. **動力伝達状態**：エンジン → クラッチ → ミッション → 15Tスプロケット → チェーン → 48T・後輪の伝達経路を示します。

## 回転数と理論車速

エンジン回転数から一次減速・段別変速比・二次減速を通して各部のrpmを求め、回転角を「部品rpm × 6 × 経過秒」で計算します。

```js
const speedKmh =
  rpm * Math.PI * 0.6492 * 60 /
  (1000 * (74/24) * gearRatio * (48/15));
```

- 一次減速：74/24
- 変速比（1〜5速）：2.846 / 1.812 / 1.318 / 1.035 / 0.821
- 二次減速：48/15
- 計算に用いる後輪径：0.6492 m

例：3000 rpm・2速の理論車速は約20.53 km/hです。高rpmでは画面の描画周期によって回転が遅く見えたり、逆転して見えたりするため、動きを観察する際は60 rpmを利用できます。

## モデルの範囲

車種資料で確認した構成をもとにした学習用の模式図です。段別のドッグ締結先・フォーク割当には推定を含み、ドラム溝・角度・ストローク・部品寸法・チェーン経路は実測形状ではありません。

Nまたはクラッチ断では、出力軸・チェーン・後輪を停止させる無負荷の定常モデルです。惰性、半クラッチ、油の引きずり、後輪からの逆駆動、ドッグの位相待ち、変速ショックは再現していません。整備手順や実機の寸法確認には、車種に対応する公式資料を使用してください。
